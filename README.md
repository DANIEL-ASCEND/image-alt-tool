# 图片 ALT 工具（Image ALT Tool）v1.3

一个给独立站产品图批量做处理的桌面小工具：把一文件夹产品图按顺序转码压缩、改名，并为每张图生成一条 ALT 文案，写进一张映射表里，方便上架时直接取用。

## 它能做什么

- **批量处理一整个文件夹**：按自然顺序（2 排在 10 前面）逐张处理，不用一张一张改。
- **真转码 + 压缩**：输出 JPG 或 WebP，默认质量 85、最大宽度 2000px（只缩小、不放大），透明底转 JPG 时垫白底。
- **改名有规律**：新文件名 = 产品名缩写-视角缩写，例如 `sample-product-main-view.jpg`；输出重名时自动加 `-v2`、`-v3`，绝不静默覆盖已有文件。
- **ALT 逐张分发**：ALT = 品牌 + 产品名 - 视角侧重短语，长尾词按顺序轮流加进 ALT（已在侧重短语或品牌产品名里出现的不重复加），超 250 字符按词边界截断。
- **原图不动**：只读源文件夹、把结果写到另一个输出文件夹；源图、源文件名都不改。
- **输出一张映射表**：`alt_tags_mapping.csv`，列为 Original_Filename / New_Filename / ALT_Text / Keyword / Out_Size_KB（UTF-8，Excel 可直接打开）。

## 它不能做什么（先说清楚，免得用错）

- **ALT 只写在映射表里，不写进图片文件本身**：上架时要把 CSV 里的 ALT 填到后台对应图片上。
- **不做 800×800 白底画布**：只做透明底转白、按比例缩放；需要固定画布尺寸的产品图，请先在修图软件里做好再处理。
- **不按图片内容自动识别**：视角策略是按文件顺序逐行分配的；如果源文件夹的顺序和图片实际内容对不上，请先排好顺序，或处理完后直接改 CSV 里的 ALT（CSV 是最终记录）。

## 快速上手

```powershell
pip install PyQt6 Pillow
python main.py
```

打开后依次填：源图片文件夹、输出保存文件夹、品牌名称、核心产品名、长尾词（逗号或换行分隔）、视角策略表，再选输出格式、质量和最大宽度，点“一键优化并打包”即可。

打包成单个可执行文件：

```powershell
pyinstaller --onefile --windowed --name SEO工具1.3 --icon app.ico main.py
```

详细步骤见 [使用说明](USAGE.md)，版本变化见 [版本记录](CHANGELOG.md)。

## 文件说明

- `main.py`：全部功能都在这一个文件里，界面和核心处理逻辑在一起；没有界面环境时也可以直接调用里面的核心处理函数。
- `presets.txt`：视角策略预设库。界面默认是 3C 预设；服装、家居、通用三套预设都在这个文件里，需要时整段粘贴替换策略表即可。
- `app.ico`：窗口图标，打包时一并带入。

## 视角策略表格式

每行三段，用 `|` 分隔：

```
文件名后缀 | 视角名 | ALT 侧重短语（英文）
```

例如：

```
main-view | Main View | Product Overall View
detail-view-1 | Detail Close-up | Build Quality and Material Detail
```
